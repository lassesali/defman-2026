SECTION 1. EXECUTIVE SUMMARY & NORMALIZATION ANALYSIS (1NF, 2NF, 3NF)
================================================================================

1.1 Overview of Legacy Schema Violations
--------------------------------------------------------------------------------
The legacy DefMan schema consisted of 5 tables (`product`, `users`,
`user_sessions`, `raport`, and `analyse`) inherited from the 2004 schema design.
While functional, it contained several First, Second, and Third Normal Form
(1NF, 2NF, 3NF) anomalies as well as data-type and primary-key scalability
bottlenecks:

  A. Naming & Primary Key Exhaustion Risks:
     - Mixed-case and Polish/Finnish legacy identifiers (`raport`, `analyse`,
       `Product`, `CustomerID`, `Whenreported`, `Discoveredby`, `Occured`).
     - `raport.ID` and `analyse.id` used `SMALLINT UNSIGNED`, capping total
       lifetime defect reports at 65,535 rows.

  B. First Normal Form (1NF) Violations:
     - Repeating Groups / Multi-Valued Column: `analyse.phase` stored multiple
       SDLC phases as a comma-delimited string (e.g., 'Implementation,Testing'),
       preventing indexed phase queries and referential integrity.
     - Non-Atomic String Timestamps & Redundant Dates: `raport.Whenreported`
       stored timestamps as `VARCHAR(32)` ('YYYY-MM-DD HH:mm'), while
       `raport.Submitted` and `analyse.submitted` duplicated the date portion
       across two tables.

  C. Second & Third Normal Form (2NF / 3NF) Violations:
     - Unnormalized Organization Attribute in `users`: `users.company` repeated
       free-text company names across user accounts.
     - Transient Session & Recovery Attributes on `users`: `users.logged`
       duplicated session state already tracked in `user_sessions`, causing
       stale "Online" badges when sessions expired. Similarly,
       `reset_token_hash` and `reset_token_expires_at` embedded 1:N recovery
       lifecycle data directly inside the `users` entity.
     - Denormalized Product Name in `raport`: `raport.Product` (`VARCHAR(100)`)
       duplicated `product.name` alongside a nullable `product_id` FK.
     - Transitive Reporter Identity in `raport`: `raport.Who` and
       `raport.Contactemail` duplicated `users.login` and `users.email` even
       when `CustomerID` referenced a valid registered user.
     - Unnormalized Fault Taxonomy & Inconsistent Enums in `analyse`:
       `analyse.classification` stored repeated IEEE 1044-1992 strings;
       priority enums differed between `raport.Priority` ('m_urgent',
       'average', 'l_urgent') and `analyse.priority` ('most urgent',
       'average', 'less urgent'); and `analyse.uniqueness` conflated defect
       duplication ('New defect', 'Already submitted') with severity ('Critical').

--------------------------------------------------------------------------------
1.2 Target 3NF Relational Model (10 Normalized Tables)
--------------------------------------------------------------------------------
  1. `products`              : Standardized from `product` (`id`, `name`, `created_at`).
  2. `companies`             : Extracted 3NF lookup table (`id`, `name`, `created_at`).
  3. `users`                 : Normalized user accounts referencing `companies(id)`
                               via `company_id`; `logged` and reset columns removed.
  4. `user_sessions`         : Active bearer tokens; derives user online presence.
  5. `password_resets`       : Decoupled password recovery tokens referencing `users(id)`.
  6. `sdlc_phases`           : 1NF lookup table for SDLC phases ('Requirements',
                               'Design', 'Implementation', 'Testing', 'Deployment',
                               'Maintenance').
  7. `fault_classifications` : 3NF lookup table for IEEE 1044-1992 fault codes.
  8. `defect_reports`        : Standardized from `raport` with `INT UNSIGNED` PK,
                               `product_id` NOT NULL FK (`ON DELETE RESTRICT`),
                               `reporter_user_id` FK (`ON DELETE SET NULL`),
                               nullable `guest_name` / `guest_email` enforced by
                               `chk_defect_reports_reporter_identity`, and `DATETIME`
                               `reported_at`.
  9. `defect_analyses`       : Standardized from `analyse` with `INT UNSIGNED`
                               `report_id` PK/FK, `classification_id` FK,
                               `uniqueness` ENUM('new','duplicate'),
                               `duplicate_of_report_id` self-referencing FK, and
                               unified `priority` ENUM('most_urgent','average','less_urgent').
 10. `analysis_phases`       : 1NF junction table (`report_id`, `phase_id`) linking
                               `defect_analyses` to `sdlc_phases`.

-- =============================================================================
-- File: 01_schema_3nf.sql
-- Description: Target 3NF Relational Schema for DefMan-2026 (MySQL 8.0+ / MariaDB 10.6+)
-- Engine: InnoDB | Charset: utf8mb4 | Collation: utf8mb4_unicode_ci
-- =============================================================================

SET NAMES utf8mb4;
SET FOREIGN_KEY_CHECKS = 0;
SET SQL_MODE = 'STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION';

-- -----------------------------------------------------------------------------
-- 1. Table: `products` (standardized from `product`)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `products` (
  `id` SMALLINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(100) NOT NULL,
  `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_products_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 2. Table: `companies` (extracted from `users.company` — 3NF)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `companies` (
  `id` SMALLINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(100) NOT NULL,
  `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_companies_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 3. Table: `users` (normalized: `company_id` FK; removed `logged` & reset cols)
-- User Levels:
--   0 = Applying (Pending Admin Approval)
--   1 = Public   (Unauthenticated / Public reporter)
--   2 = Customer (Authenticated defect reporter)
--   3 = Analyzer (Developer / QA triage & IEEE fault cost tracking)
--   4 = Admin    (Full system access, user approval & product CRUD)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `users` (
  `id` SMALLINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `login` VARCHAR(64) NOT NULL,
  `password` VARCHAR(255) NOT NULL COMMENT 'Argon2id password hash (PASSWORD_ARGON2ID)',
  `email` VARCHAR(255) NOT NULL,
  `userlevel` TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '0=Applying..4=Admin',
  `company_id` SMALLINT UNSIGNED NULL DEFAULT NULL,
  `phone` VARCHAR(50) NULL DEFAULT NULL,
  `name` VARCHAR(100) NULL DEFAULT NULL,
  `activate` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '0=Pending/Inactive, 1=Active',
  `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_users_login` (`login`),
  UNIQUE KEY `uk_users_email` (`email`),
  KEY `idx_users_company_id` (`company_id`),
  KEY `idx_users_level_activate` (`userlevel`, `activate`),
  CONSTRAINT `fk_users_company`
    FOREIGN KEY (`company_id`) REFERENCES `companies` (`id`)
    ON DELETE SET NULL ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 4. Table: `user_sessions` (active rows derive user online status)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `user_sessions` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `user_id` SMALLINT UNSIGNED NOT NULL,
  `token_hash` CHAR(64) NOT NULL COMMENT 'SHA-256 hash of 256-bit random_bytes token',
  `ip_address` VARCHAR(45) NULL DEFAULT NULL,
  `user_agent` VARCHAR(255) NULL DEFAULT NULL,
  `expires_at` DATETIME NOT NULL,
  `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_sessions_token_hash` (`token_hash`),
  KEY `idx_user_sessions_user_expires` (`user_id`, `expires_at`),
  KEY `idx_user_sessions_expires_at` (`expires_at`),
  CONSTRAINT `fk_user_sessions_user`
    FOREIGN KEY (`user_id`) REFERENCES `users` (`id`)
    ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 5. Table: `password_resets` (decoupled from `users` — 3NF)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `password_resets` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
  `user_id` SMALLINT UNSIGNED NOT NULL,
  `token_hash` CHAR(64) NOT NULL COMMENT 'SHA-256 hash of recovery token',
  `expires_at` DATETIME NOT NULL,
  `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_password_resets_token_hash` (`token_hash`),
  KEY `idx_password_resets_user_expires` (`user_id`, `expires_at`),
  CONSTRAINT `fk_password_resets_user`
    FOREIGN KEY (`user_id`) REFERENCES `users` (`id`)
    ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 6. Table: `sdlc_phases` (lookup table for SDLC origin phases — 1NF)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `sdlc_phases` (
  `id` TINYINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(64) NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_sdlc_phases_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 7. Table: `fault_classifications` (IEEE 1044-1992 fault classification — 3NF)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `fault_classifications` (
  `id` SMALLINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `code` VARCHAR(100) NOT NULL,
  `description` VARCHAR(255) NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_fault_classifications_code` (`code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 8. Table: `defect_reports` (standardized & normalized from `raport`)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `defect_reports` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT,
  `product_id` SMALLINT UNSIGNED NOT NULL,
  `environment` TEXT NULL DEFAULT NULL,
  `reporter_user_id` SMALLINT UNSIGNED NULL DEFAULT NULL,
  `guest_name` VARCHAR(100) NULL DEFAULT NULL,
  `guest_email` VARCHAR(255) NULL DEFAULT NULL,
  `reported_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `title` VARCHAR(255) NOT NULL,
  `description` TEXT NOT NULL,
  `discovered_by` VARCHAR(100) NULL DEFAULT NULL,
  `person_type` ENUM('Customer', 'Developer', 'Tester') NOT NULL DEFAULT 'Customer',
  `occurred_on` DATE NOT NULL,
  `location` VARCHAR(255) NULL DEFAULT NULL,
  `initial_severity` ENUM('minor', 'major', 'critical') NOT NULL DEFAULT 'minor',
  `initial_priority` ENUM('most_urgent', 'average', 'less_urgent') NOT NULL DEFAULT 'average',
  `additional_info` TEXT NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_defect_reports_product_id` (`product_id`),
  KEY `idx_defect_reports_reporter_user_id` (`reporter_user_id`),
  KEY `idx_defect_reports_reported_at` (`reported_at` DESC),
  KEY `idx_defect_reports_severity_reported` (`initial_severity`, `reported_at` DESC),
  KEY `idx_defect_reports_priority_reported` (`initial_priority`, `reported_at` DESC),
  CONSTRAINT `fk_defect_reports_product`
    FOREIGN KEY (`product_id`) REFERENCES `products` (`id`)
    ON DELETE RESTRICT ON UPDATE CASCADE,
  CONSTRAINT `fk_defect_reports_reporter`
    FOREIGN KEY (`reporter_user_id`) REFERENCES `users` (`id`)
    ON DELETE SET NULL ON UPDATE CASCADE,
  CONSTRAINT `chk_defect_reports_reporter_identity`
    CHECK (
      `reporter_user_id` IS NOT NULL
      OR (`guest_name` IS NOT NULL AND `guest_email` IS NOT NULL)
    )
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 9. Table: `defect_analyses` (standardized & normalized from `analyse`)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `defect_analyses` (
  `report_id` INT UNSIGNED NOT NULL COMMENT '1:1 Primary & Foreign Key to defect_reports.id',
  `developer_description` TEXT NULL DEFAULT NULL,
  `classification_id` SMALLINT UNSIGNED NULL DEFAULT NULL,
  `date_originated` DATE NULL DEFAULT NULL,
  `activity_originated` TEXT NULL DEFAULT NULL,
  `deliverable` VARCHAR(255) NULL DEFAULT NULL,
  `what_to_do` TEXT NULL DEFAULT NULL,
  `assigned_on` DATE NULL DEFAULT NULL,
  `uniqueness` ENUM('new', 'duplicate') NOT NULL DEFAULT 'new',
  `duplicate_of_report_id` INT UNSIGNED NULL DEFAULT NULL,
  `priority` ENUM('most_urgent', 'average', 'less_urgent') NOT NULL DEFAULT 'average',
  `severity` ENUM('minor', 'major', 'critical') NOT NULL DEFAULT 'minor',
  `workaround` TEXT NULL DEFAULT NULL,
  `proposed_fix` TEXT NULL DEFAULT NULL,
  `status` ENUM('submitted', 'assigned', 'postponed', 'opened', 'fixed', 'resolved', 'closed') NOT NULL DEFAULT 'submitted',
  `fix_description` TEXT NULL DEFAULT NULL,
  `fix_started_on` DATE NULL DEFAULT NULL,
  `fix_completed_on` DATE NULL DEFAULT NULL,
  `fix_impact` TEXT NULL DEFAULT NULL,
  `fix_effort` DECIMAL(8,2) UNSIGNED NULL DEFAULT NULL,
  `fix_cost` DECIMAL(10,2) UNSIGNED NULL DEFAULT NULL,
  `resolution_description` TEXT NULL DEFAULT NULL,
  `resolution_completed_on` DATE NULL DEFAULT NULL,
  `resolution_closed_on` DATE NULL DEFAULT NULL,
  `cost_of_defect` DECIMAL(10,2) UNSIGNED NULL DEFAULT NULL,
  `activity_found` TEXT NULL DEFAULT NULL,
  PRIMARY KEY (`report_id`),
  KEY `idx_defect_analyses_classification_id` (`classification_id`),
  KEY `idx_defect_analyses_duplicate_of` (`duplicate_of_report_id`),
  KEY `idx_defect_analyses_status_priority` (`status`, `priority`, `severity`),
  CONSTRAINT `fk_defect_analyses_report`
    FOREIGN KEY (`report_id`) REFERENCES `defect_reports` (`id`)
    ON DELETE CASCADE ON UPDATE CASCADE,
  CONSTRAINT `fk_defect_analyses_classification`
    FOREIGN KEY (`classification_id`) REFERENCES `fault_classifications` (`id`)
    ON DELETE SET NULL ON UPDATE CASCADE,
  CONSTRAINT `fk_defect_analyses_duplicate_of`
    FOREIGN KEY (`duplicate_of_report_id`) REFERENCES `defect_reports` (`id`)
    ON DELETE SET NULL ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- -----------------------------------------------------------------------------
-- 10. Table: `analysis_phases` (junction table for defect_analyses <-> sdlc_phases — 1NF)
-- -----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS `analysis_phases` (
  `report_id` INT UNSIGNED NOT NULL,
  `phase_id` TINYINT UNSIGNED NOT NULL,
  PRIMARY KEY (`report_id`, `phase_id`),
  KEY `idx_analysis_phases_phase_id` (`phase_id`),
  CONSTRAINT `fk_analysis_phases_analysis`
    FOREIGN KEY (`report_id`) REFERENCES `defect_analyses` (`report_id`)
    ON DELETE CASCADE ON UPDATE CASCADE,
  CONSTRAINT `fk_analysis_phases_phase`
    FOREIGN KEY (`phase_id`) REFERENCES `sdlc_phases` (`id`)
    ON DELETE RESTRICT ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

SET FOREIGN_KEY_CHECKS = 1;

CREATE TABLE IF NOT EXISTS `products` (
  `id` SMALLINT UNSIGNED NOT NULL AUTO_INCREMENT,

  `id` SMALLINT UNSIGNED NOT NULL AUTO_INCREMENT,

  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_companies_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Add `company_id` to `users` if migrating in-place from legacy `users`
SET @col_exists := (
  SELECT COUNT(*)
  FROM INFORMATION_SCHEMA.COLUMNS
  WHERE TABLE_SCHEMA = DATABASE()
    AND TABLE_NAME = 'users'
    AND COLUMN_NAME = 'company_id'
);
SET @sql_add_company_id := IF(
  @col_exists = 0,
  'ALTER TABLE `users` ADD COLUMN `company_id` SMALLINT UNSIGNED NULL DEFAULT NULL AFTER `userlevel`, ADD KEY `idx_users_company_id` (`company_id`), ADD CONSTRAINT `fk_users_company` FOREIGN KEY (`company_id`) REFERENCES `companies` (`id`) ON DELETE SET NULL ON UPDATE CASCADE',
  'SELECT 1'
);
PREPARE stmt FROM @sql_add_company_id;
EXECUTE stmt;
DEALLOCATE PREPARE stmt;

    public function createProduct(array $body): array
    {

        $name = trim(strip_tags((string) ($body['name'] ?? '')));
        if ($name === '') {
            http_response_code(422);
            return ['error' => 'Empty Product name!'];

            http_response_code(409);
            return ['error' => "Product '{$name}' already exists."];
        }

        $id = $this->productRepository->create($name);
        http_response_code(201);
        return [
            'id'      => $id,
            'name'    => $name,
            'message' => "You added new product: {$name} in database.",
        ];
    }

        $this->rbac->requireLevel(UserLevel::ADMIN);

            http_response_code(409);
            return ['error' => $e->getMessage()];

<?php
declare(strict_types=1);

namespace DefMan\Repository;

use DefMan\Domain\Enum\DefectPriority;
use DefMan\Domain\Enum\DefectSeverity;

/**
 * Defect Analysis, Fix & Resolution Repository (`defect_analyses`, `fault_classifications`, `sdlc_phases`, `analysis_phases` — 3NF)
 * Refactored from: form_alist.php, form_analyze.php, form_analyzed.php,
 *                  form_deffix.php, form_defreso.php, db.php (deleteanalyze)
 */
final readonly class AnalysisRepository
{
    public function __construct(private PDO $pdo) {}

    /**
     * Resolves an IEEE 1044-1992 fault classification code to `fault_classifications.id`
     */
    private function resolveClassificationId(string $code): int
    {
        $trimmed = trim(strip_tags($code));
        if ($trimmed === '') {
            $trimmed = IeeeFaultType::OTHER->value;
        }

        $stmt = $this->pdo->prepare(
            'INSERT INTO `fault_classifications` (`code`) VALUES (:code)
             ON DUPLICATE KEY UPDATE `id` = LAST_INSERT_ID(`id`)'
        );
        $stmt->execute([':code' => $trimmed]);
        return (int) $this->pdo->lastInsertId();
    }

    /**
     * Syncs the 1NF `analysis_phases` junction table for a given `report_id`
     *
     * @param list<string> $phases
     */
    private function syncAnalysisPhases(int $reportId, array $phases): void
    {
        $deleteStmt = $this->pdo->prepare('DELETE FROM `analysis_phases` WHERE `report_id` = :report_id');
        $deleteStmt->execute([':report_id' => $reportId]);

        $phaseUpsertStmt = $this->pdo->prepare(
            'INSERT INTO `sdlc_phases` (`name`) VALUES (:name)
             ON DUPLICATE KEY UPDATE `id` = LAST_INSERT_ID(`id`)'
        );
        $junctionStmt = $this->pdo->prepare(
            'INSERT IGNORE INTO `analysis_phases` (`report_id`, `phase_id`) VALUES (:report_id, :phase_id)'
        );

        foreach ($phases as $rawPhase) {
            $phaseName = trim(strip_tags((string) $rawPhase));
            if ($phaseName === '') {
                continue;
            }
            $phaseUpsertStmt->execute([':name' => $phaseName]);
            $phaseId = (int) $this->pdo->lastInsertId();
            $junctionStmt->execute([
                ':report_id' => $reportId,
                ':phase_id'  => $phaseId,
            ]);
        }
    }

    /**
     * Returns the full Analyzer Queue with lead-time metrics:
     * - submitted_to_assigned_days
     * - submitted_to_fixed_days
     * - submitted_to_resolved_days
     * - assigned_to_fixed_days
     * - assigned_to_resolved_days
     */
    public function getAnalyzerQueue(?string $sort = 'all'): array
    {
        $whereSql = '';
        $params   = [];

        if (in_array($sort, ['critical', 'major', 'minor'], true)) {
            $whereSql        = 'WHERE COALESCE(da.`severity`, dr.`initial_severity`) = :sort';
            $params[':sort'] = $sort;
        } elseif (in_array($sort, ['most urgent', 'average', 'less urgent', 'most_urgent', 'less_urgent'], true)) {
            $whereSql        = 'WHERE COALESCE(da.`priority`, dr.`initial_priority`) = :sort';
            $params[':sort'] = DefectPriority::fromInput($sort)->dbValue();
        } elseif (in_array($sort, ['submitted', 'assigned', 'postponed', 'opened', 'fixed', 'resolved', 'closed'], true)) {
            $whereSql        = "WHERE COALESCE(da.`status`, 'submitted') = :sort";
            $params[':sort'] = $sort;
        }

        $orderBySql = match ($sort) {
            'date'  => 'dr.`reported_at` DESC, dr.`id` DESC',
            default => "FIELD(COALESCE(da.`priority`, dr.`initial_priority`, 'average'), 'most_urgent', 'average', 'less_urgent') ASC, dr.`reported_at` DESC",
        };

        $sql = "
            SELECT
                dr.`id` AS `id`,
                p.`name` AS `product`,
                dr.`title` AS `title`,
                dr.`description` AS `report_description`,
                dr.`environment` AS `environment`,
                dr.`occurred_on` AS `occured`,
                COALESCE(u.`email`, dr.`guest_email`, '') AS `contact_email`,
                COALESCE(u.`login`, dr.`guest_name`, '') AS `who`,
                dr.`initial_severity` AS `report_severity`,
                CASE dr.`initial_priority`
                    WHEN 'most_urgent' THEN 'm_urgent'
                    WHEN 'less_urgent' THEN 'l_urgent'
                    ELSE 'average'
                END AS `report_priority`,
                DATE(dr.`reported_at`) AS `report_submitted`,
                da.`developer_description` AS `devdesc`,
                COALESCE(fc.`code`, 'Other') AS `classification`,
                da.`date_originated` AS `dateoriginated`,
                ph.`phases_csv` AS `phase`,
                da.`activity_originated` AS `actoriginated`,
                da.`deliverable`,
                da.`what_to_do` AS `whattodo`,
                DATE(dr.`reported_at`) AS `submitted`,
                da.`assigned_on` AS `assigned`,
                CASE da.`uniqueness`
                    WHEN 'duplicate' THEN 'Already submitted'
                    ELSE 'New defect'
                END AS `uniqueness`,
                da.`duplicate_of_report_id`,
                COALESCE(da.`severity`, dr.`initial_severity`) AS `severity`,
                CASE COALESCE(da.`priority`, dr.`initial_priority`)
                    WHEN 'most_urgent' THEN 'most urgent'
                    WHEN 'less_urgent' THEN 'less urgent'
                    ELSE 'average'
                END AS `priority`,
                da.`workaround`,
                da.`proposed_fix` AS `proposedfix`,
                COALESCE(da.`status`, 'submitted') AS `status`,
                da.`fix_description` AS `fixdesc`,
                da.`fix_started_on` AS `fixstarted`,
                da.`fix_completed_on` AS `fixcomplete`,
                da.`fix_impact` AS `fiximpact`,
                COALESCE(da.`fix_effort`, 0.00) AS `fixeffort`,
                COALESCE(da.`fix_cost`, 0.00) AS `fixcost`,
                da.`resolution_description` AS `resodesc`,
                da.`resolution_completed_on` AS `resocomplete`,
                da.`resolution_closed_on` AS `resoclosed`,
                COALESCE(da.`cost_of_defect`, 0.00) AS `costofdefect`,
                da.`activity_found` AS `actfound`,
                DATEDIFF(CURDATE(), DATE(dr.`reported_at`)) AS `days_open`,
                CASE WHEN da.`assigned_on` IS NOT NULL
                     THEN DATEDIFF(da.`assigned_on`, DATE(dr.`reported_at`))
                     ELSE NULL END AS `submitted_to_assigned_days`,
                CASE WHEN da.`fix_completed_on` IS NOT NULL
                     THEN DATEDIFF(da.`fix_completed_on`, DATE(dr.`reported_at`))
                     ELSE NULL END AS `submitted_to_fixed_days`,
                CASE WHEN da.`resolution_completed_on` IS NOT NULL
                     THEN DATEDIFF(da.`resolution_completed_on`, DATE(dr.`reported_at`))
                     ELSE NULL END AS `submitted_to_resolved_days`,
                CASE WHEN da.`fix_completed_on` IS NOT NULL AND da.`assigned_on` IS NOT NULL
                     THEN DATEDIFF(da.`fix_completed_on`, da.`assigned_on`)
                     ELSE NULL END AS `assigned_to_fixed_days`,
                CASE WHEN da.`resolution_completed_on` IS NOT NULL AND da.`assigned_on` IS NOT NULL
                     THEN DATEDIFF(da.`resolution_completed_on`, da.`assigned_on`)
                     ELSE NULL END AS `assigned_to_resolved_days`
            FROM `defect_reports` dr
            INNER JOIN `products` p ON p.`id` = dr.`product_id`
            LEFT JOIN `users` u ON u.`id` = dr.`reporter_user_id`
            LEFT JOIN `defect_analyses` da ON da.`report_id` = dr.`id`
            LEFT JOIN `fault_classifications` fc ON fc.`id` = da.`classification_id`
            LEFT JOIN (
                SELECT
                    ap.`report_id`,
                    GROUP_CONCAT(sp.`name` ORDER BY sp.`id` SEPARATOR ',') AS `phases_csv`
                FROM `analysis_phases` ap
                INNER JOIN `sdlc_phases` sp ON sp.`id` = ap.`phase_id`
                GROUP BY ap.`report_id`
            ) ph ON ph.`report_id` = dr.`id`
            {$whereSql}
            ORDER BY {$orderBySql}
        ";

        $stmt = $this->pdo->prepare($sql);
        $stmt->execute($params);
        $rows = $stmt->fetchAll();

        foreach ($rows as &$row) {
            $faultEnum = IeeeFaultType::fromLegacyString((string) $row['classification']);
            $row['classification_color'] = sprintf('#%06X', $faultEnum->hexColor());
            $row['phases'] = !empty($row['phase']) ? explode(',', (string) $row['phase']) : [];
        }

        return $rows;
    }

    /**

            ? (int) $data['duplicate_of_report_id']
            : null;

                  `workaround`             = VALUES(`workaround`),
                  `proposed_fix`           = VALUES(`proposed_fix`),

            $stmt->execute([
