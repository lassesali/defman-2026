================================================================================

1.1 Rationale: Replacing 1992 IEEE Fault & Waterfall Phase-Cost Multipliers
--------------------------------------------------------------------------------
The original DefMan 2004 analytical model was built around the 1992 draft of
IEEE Std 1044 and 1980s waterfall phase-cost multiplier heuristics:
  - It assumed a fixed hourly rate (e.g., 30 EUR/hour) multiplied by arbitrary
    phase-lag cost multipliers (`fixeffort` -> `fixcost` -> `costofdefect`).
  - It conflated observed failure symptoms with underlying engineering root
    causes in a single flat 1992 fault string (`Logic`, `Computational`,
    `Data handling`, `Document quality`, `Enhancement`, `Caused by a prev. Fix`).
  - It recorded only coarse calendar dates (`DATE`) rather than high-resolution
    timestamps (`DATETIME`), making sub-day Triage Lead Time and Mean Time To
    Recovery (MTTR) impossible to compute accurately.
  - It lacked deployment environment tracking (`DEV`, `CI`, `STAGING`, `PROD`),
    commit/build traceability (`introducing_ref`, `resolution_ref`), and explicit
    regression flags (`is_regression`).

DefMan 2026 replaces these obsolete waterfall cost multipliers with:
  1. IEEE Std 1044-2009 Anomaly Classification (separating observed Failure
     Symptom Category from Engineering Root Cause Type).
  2. DORA & Flow Engineering Telemetry computed directly from real timestamps,
     environments, regression flags, and actual engineering effort hours.

--------------------------------------------------------------------------------
1.2 IEEE Std 1044-2009 Dual-Axis Anomaly Classification
--------------------------------------------------------------------------------
  A. Observed Symptom Category (`symptom_category`):
     - Application Crash / Hang
     - Data Corruption / Loss
     - Incorrect Calculation / Output
     - Authentication / Security Failure
     - UI / Rendering Anomaly
     - Performance / Latency Degradation
     - API / Integration Failure
     - Other Symptom

  B. Engineering Root Cause Type (`root_cause_type` / `IeeeFaultType`):
     - Code / Logic
     - Computational
     - Interface / Integration
     - Data / Schema
     - Concurrency / Timing
     - Configuration / Environment
     - Security / Access Control
     - Requirements / Specification
     - Architecture / Design
     - Documentation
     - Regression
     - Other

--------------------------------------------------------------------------------
1.3 DORA & Flow Engineering Metrics (AnalysisRepository.php)
--------------------------------------------------------------------------------
All synthetic EUR phase-cost multipliers have been replaced in
`AnalysisRepository::getDoraTelemetrySummary()` and `getAnalyzerQueue()` with
real SQL aggregations over `defect_reports` and `defect_analyses`:

  1. Mean Time To Resolution (MTTR):
     - Formula: AVG(TIMESTAMPDIFF(SECOND, dr.reported_at, da.resolved_at) / 3600.0)
     - Measures actual elapsed hours from defect report creation (`reported_at`)
       to verified engineering resolution (`resolved_at`).

  2. Triage Lead Time:
     - Formula: AVG(TIMESTAMPDIFF(SECOND, dr.reported_at, da.triaged_at) / 3600.0)
     - Measures elapsed hours from defect submission (`reported_at`) to developer
       triage and root-cause classification (`triaged_at`).

  3. Production Escape Rate:
     - Formula: (COUNT(detected_environment = 'PROD') / COUNT(*)) * 100
     - Tracks the percentage of anomalies escaping pre-production quality gates
       (`DEV`, `CI`, `STAGING`) into `PROD`, alongside per-environment counts.

  4. Regression Rate:
     - Formula: (COUNT(is_regression = TRUE) / COUNT(*)) * 100
     - Tracks the ratio of anomalies introduced by a prior fix, refactor, or
       release (`is_regression = 1`), linked via `introducing_ref`.

  5. Actual Effort Hours by IEEE 1044-2009 Root Cause:
     - Aggregates `SUM(actual_effort_hours)`, `AVG(actual_effort_hours)`,
       `AVG(mttr_hours)`, `prod_escape_count`, and `regression_count` grouped
       by `root_cause_type`.

--------------------------------------------------------------------------------
1.4 Schema & Legacy Mapping Matrix
--------------------------------------------------------------------------------
1992 / 2004 Construct            -> 2026 IEEE 1044-2009 & DORA Construct
--------------------------------------------------------------------------------
analyse.classification           -> defect_analyses.root_cause_type (VARCHAR(100))
                                    + defect_analyses.symptom_category (VARCHAR(100))
                                    + fault_classifications.code (FK)
raport.Environment (free text)   -> defect_reports.environment (TEXT)
                                    + detected_environment ENUM('DEV','CI','STAGING','PROD')
"Caused by a prev. Fix"          -> is_regression BOOLEAN NOT NULL DEFAULT FALSE
                                    + root_cause_type = 'Regression'
(Untracked build/commit origin)  -> defect_analyses.introducing_ref (VARCHAR(128))
(Untracked fix commit/PR)        -> defect_analyses.resolution_ref (VARCHAR(128))
analyse.fixeffort                -> defect_analyses.actual_effort_hours (DECIMAL(8,2))
analyse.fixcost / costofdefect   -> Deprecated (nullable legacy columns; replaced
                                    by DORA MTTR & Root Cause Effort Breakdown)
analyse.assigned (DATE)          -> defect_analyses.triaged_at (DATETIME)
analyse.resocomplete (DATE)      -> defect_analyses.resolved_at (DATETIME)

--------------------------------------------------------------------------------
1.5 Backward Compatibility Preservation (`03_legacy_views.sql`)
--------------------------------------------------------------------------------
Legacy 2004 SQL queries against `product`, `raport`, and `analyse` continue to
resolve without error:
  - `COALESCE(da.root_cause_type, fc.code) AS classification`
  - `COALESCE(da.assigned_on, DATE(da.triaged_at)) AS assigned`
  - `COALESCE(da.fix_completed_on, DATE(da.resolved_at)) AS fixcomplete`
  - `COALESCE(da.actual_effort_hours, da.fix_effort) AS fixeffort`
  - `COALESCE(da.resolution_completed_on, DATE(da.resolved_at)) AS resocomplete`

CREATE OR REPLACE VIEW `raport` AS
SELECT
  dr.`id` AS `ID`,
  p.`name` AS `Product`,
  dr.`product_id` AS `product_id`,
  dr.`environment` AS `Environment`,
  dr.`reporter_user_id` AS `CustomerID`,
  COALESCE(u.`login`, dr.`guest_name`, '') AS `Who`,
  COALESCE(u.`email`, dr.`guest_email`, '') AS `Contactemail`,
  DATE_FORMAT(dr.`reported_at`, '%Y-%m-%d %H:%i') AS `Whenreported`,
  dr.`title` AS `Title`,
  dr.`description` AS `Description`,
  dr.`discovered_by` AS `Discoveredby`,
  dr.`person_type` AS `Persontype`,
  dr.`occurred_on` AS `Occured`,
  dr.`location` AS `Location`,
  dr.`initial_severity` AS `Severity`,
  CASE dr.`initial_priority`
    WHEN 'most_urgent' THEN 'm_urgent'
    WHEN 'average'     THEN 'average'
    WHEN 'less_urgent' THEN 'l_urgent'
  END AS `Priority`,
  DATE(dr.`reported_at`) AS `Submitted`,
  dr.`additional_info` AS `Addinfo`
FROM `defect_reports` dr
INNER JOIN `products` p
  ON p.`id` = dr.`product_id`
LEFT JOIN `users` u
  ON u.`id` = dr.`reporter_user_id`;

CREATE OR REPLACE VIEW `analyse` AS
SELECT
  da.`report_id` AS `id`,
  da.`developer_description` AS `devdesc`,
  COALESCE(da.`root_cause_type`, fc.`code`) AS `classification`,
  da.`date_originated` AS `dateoriginated`,
  ph.`phases_csv` AS `phase`,
  da.`activity_originated` AS `actoriginated`,
  da.`deliverable` AS `deliverable`,
  da.`what_to_do` AS `whattodo`,
  DATE(dr.`reported_at`) AS `submitted`,
  COALESCE(da.`assigned_on`, DATE(da.`triaged_at`)) AS `assigned`,
  CASE da.`uniqueness`
    WHEN 'duplicate' THEN 'Already submitted'
    WHEN 'new'       THEN 'New defect'
  END AS `uniqueness`,
  CASE da.`priority`
    WHEN 'most_urgent' THEN 'most urgent'
    WHEN 'average'     THEN 'average'
    WHEN 'less_urgent' THEN 'less urgent'
  END AS `priority`,
  da.`severity` AS `severity`,
  da.`workaround` AS `workaround`,
  da.`proposed_fix` AS `proposedfix`,
  da.`status` AS `status`,
  da.`fix_description` AS `fixdesc`,
  da.`fix_started_on` AS `fixstarted`,
  da.`fix_completed_on` AS `fixcomplete`,
  da.`fix_impact` AS `fiximpact`,
  COALESCE(da.`actual_effort_hours`, da.`fix_effort`) AS `fixeffort`,
  da.`fix_cost` AS `fixcost`,
  da.`resolution_description` AS `resodesc`,
  COALESCE(da.`resolution_completed_on`, DATE(da.`resolved_at`)) AS `resocomplete`,
  da.`resolution_closed_on` AS `resoclosed`,
  da.`cost_of_defect` AS `costofdefect`,
  da.`activity_found` AS `actfound`
FROM `defect_analyses` da
INNER JOIN `defect_reports` dr
  ON dr.`id` = da.`report_id`
LEFT JOIN `fault_classifications` fc
  ON fc.`id` = da.`classification_id`
LEFT JOIN (
  SELECT
    ap.`report_id`,
    GROUP_CONCAT(sp.`name` ORDER BY sp.`id` SEPARATOR ',') AS `phases_csv`
  FROM `analysis_phases` ap
  INNER JOIN `sdlc_phases` sp
    ON sp.`id` = ap.`phase_id`
  GROUP BY ap.`report_id`
) ph
  ON ph.`report_id` = da.`report_id`;

  da.`developer_description` AS `devdesc`,
  COALESCE(da.`root_cause_type`, fc.`code`) AS `classification`,
  da.`date_originated` AS `dateoriginated`,
  ph.`phases_csv` AS `phase`,
  da.`activity_originated` AS `actoriginated`,
  da.`deliverable` AS `deliverable`,
  da.`what_to_do` AS `whattodo`,

  COALESCE(da.`assigned_on`, DATE(da.`triaged_at`)) AS `assigned`,

    WHEN 'new'       THEN 'New defect'
  END AS `uniqueness`,
  CASE da.`priority`
    WHEN 'most_urgent' THEN 'most urgent'
    WHEN 'average'     THEN 'average'
    WHEN 'less_urgent' THEN 'less urgent'
  END AS `priority`,
  da.`severity` AS `severity`,
  da.`workaround` AS `workaround`,
  da.`proposed_fix` AS `proposedfix`,
  da.`status` AS `status`,
  da.`fix_description` AS `fixdesc`,
  da.`fix_started_on` AS `fixstarted`,
  COALESCE(da.`fix_completed_on`, DATE(da.`resolved_at`)) AS `fixcomplete`,
  da.`fix_impact` AS `fiximpact`,
  COALESCE(da.`actual_effort_hours`, da.`fix_effort`) AS `fixeffort`,
  da.`fix_cost` AS `fixcost`,
  da.`resolution_description` AS `resodesc`,
  COALESCE(da.`resolution_completed_on`, DATE(da.`resolved_at`)) AS `resocomplete`,
  da.`resolution_closed_on` AS `resoclosed`,
  da.`cost_of_defect` AS `costofdefect`,

INNER JOIN `defect_reports` dr

LEFT JOIN `fault_classifications` fc
  ON fc.`id` = da.`classification_id`

  FROM `analysis_phases` ap
  INNER JOIN `sdlc_phases` sp
    ON sp.`id` = ap.`phase_id`

) ph
  ON ph.`report_id` = da.`report_id`;

    private function syncAnalysisPhases(int $reportId, array $phases): void

    /**
     * Normalizes a datetime or date input string to MySQL DATETIME ('Y-m-d H:i:s')
     */
    private function normalizeDateTime(?string $value, ?string $fallbackTime = null): ?string
    {
        $trimmed = trim((string) $value);
        if ($trimmed === '') {
            return $fallbackTime;
        }
        $normalized = str_replace('T', ' ', $trimmed);
        if (preg_match('/^\d{4}-\d{2}-\d{2}$/', $normalized) === 1) {
            return $normalized . ' 12:00:00';
        }
        if (preg_match('/^\d{4}-\d{2}-\d{2} \d{2}:\d{2}$/', $normalized) === 1) {
            return $normalized . ':00';
        }
        return $normalized;

            if ($who === '') {

                $errors[] = 'Bad Contact email address!';
            }
        }

        if (empty(trim((string) ($body['title'] ?? '')))) {
            $errors[] = 'Empty Title!';
        }
        if (empty(trim((string) ($body['description'] ?? '')))) {
            $errors[] = 'Empty Description!';

        if (empty($body['occured']) || !$this->isValidDate((string) $body['occured'])) {

        if (empty($body['product'])) {
            $errors[] = 'Empty Product!';
        }
        if (empty($body['severity'])) {
            $errors[] = 'Empty Severity!';
        }
        if (empty($body['priority'])) {
            $errors[] = 'Empty Priority!';

        if (empty($body['persontype'])) {

    }

     * Preserves 2004 date bounds validation (1980 < year < 2100) from form_raport.php

    private function isValidDate(string $dateStr): bool
    {
        $parts = explode('-', $dateStr);
        if (count($parts) !== 3) {
            return false;
        }
        [$year, $month, $day] = array_map('intval', $parts);
        return $year > 1980 && $year < 2100 && checkdate($month, $day, $year);
    }

function formatHoursMetric(hours: number | null | undefined): string {
  if (hours === null || hours === undefined || Number.isNaN(Number(hours))) {
    return '—';
  }
  const numeric = Number(hours);
  if (numeric < 24) {
    return `${numeric.toFixed(1)}h`;
  }
  const days = (numeric / 24).toFixed(1);
  return `${numeric.toFixed(1)}h (${days}d)`;
}

export function DefectResolutionForm({
  defectId,
  onSaved,
}: DefectResolutionFormProps): React.ReactElement {
  const [statusMessage, setStatusMessage] = useState<string | null>(null);
  const [errorMessage, setErrorMessage] = useState<string | null>(null);

  const [form, setForm] = useState({
    status: DefectStatus.RESOLVED,
    root_cause_type: IeeeFaultType.CODE_LOGIC as string,
    introducing_ref: '',
    resolution_ref: '',
    actual_effort_hours: 2.5,
    is_regression: false,
    resolved_at: new Date().toISOString().slice(0, 16),
    fixdesc: '',
    fixstarted: new Date().toISOString().slice(0, 10),
    fixcomplete: new Date().toISOString().slice(0, 10),
    fiximpact: '',
    resodesc: '',
    resocomplete: new Date().toISOString().slice(0, 10),
    resoclosed: new Date().toISOString().slice(0, 10),
  });

  useEffect(function loadResolutionDetailsEffect() {
    defmanApi.getDefectById(defectId).then(function handleDefectResponse(res) {
      if (res.analysis) {
        const a = res.analysis;
        const effortHours = Number(a.actual_effort_hours ?? a.fixeffort ?? 2.5);
        setForm({
          status: a.status || DefectStatus.RESOLVED,
          root_cause_type: (a.root_cause_type || a.classification || IeeeFaultType.CODE_LOGIC) as string,
          introducing_ref: a.introducing_ref || '',
          resolution_ref: a.resolution_ref || '',
          actual_effort_hours: effortHours,
          is_regression: Boolean(a.is_regression ?? res.is_regression),
          resolved_at: a.resolved_at
            ? a.resolved_at.replace(' ', 'T').slice(0, 16)
            : new Date().toISOString().slice(0, 16),
          fixdesc: a.fixdesc || '',
          fixstarted: a.fixstarted || new Date().toISOString().slice(0, 10),
          fixcomplete: a.fixcomplete || new Date().toISOString().slice(0, 10),
          fiximpact: a.fiximpact || '',
          resodesc: a.resodesc || '',
          resocomplete: a.resocomplete || new Date().toISOString().slice(0, 10),
          resoclosed: a.resoclosed || new Date().toISOString().slice(0, 10),
        });
      }
    });
  }, [defectId]);

        onSaved();
      }

      setErrorMessage(err instanceof Error ? err.message : 'Resolution save failed');
    }

            </span>
            <select

                setForm({ ...form, root_cause_type: e.target.value });
              }}
              className="mt-1 w-full rounded bg-slate-800 border border-slate-600 px-2.5 py-1.5"
            >

            <input

                setForm({ ...form, resolution_ref: e.target.value });

              placeholder="e.g. git:e83a11f (pr-412 / v1.5.3)"

function mapStatusToLaneIndex(status: DefectStatus | string): number {
  switch (status) {
    case DefectStatus.SUBMITTED:
    case DefectStatus.POSTPONED:
      return 0;
    case DefectStatus.ASSIGNED:
    case DefectStatus.OPENED:
      return 1;
    case DefectStatus.FIXED:

    case DefectStatus.CLOSED:
      return 3;
    default:

function getRootCauseHexColor(rootCauseOrClassification: string): number {
  const normalized = (rootCauseOrClassification || '').trim();
  if (normalized in IEEE_FAULT_HEX_COLORS) {
    return IEEE_FAULT_HEX_COLORS[normalized];
  }
  const match = Object.values(IeeeFaultType).find(function matchFaultCase(ft) {
    return ft.toLowerCase() === normalized.toLowerCase();
  });
  return match
    ? IEEE_FAULT_HEX_COLORS[match]
    : IEEE_FAULT_HEX_COLORS[IeeeFaultType.OTHER];
}

function getSeverityGlowColor(
  severity: DefectSeverity | string,
  priority: string,
  isRegression: boolean
): {
  color: number;
  alpha: number;
  width: number;
} {
  if (severity === DefectSeverity.CRITICAL) {
    return { color: 0xff2e4c, alpha: 0.92, width: 5 };
  }
  if (isRegression || severity === DefectSeverity.MAJOR || priority === 'most urgent') {
    return { color: 0xf59e0b, alpha: 0.8, width: 3.5 };
  }
  return { color: 0x38bdf8, alpha: 0.45, width: 2 };
}

function computeNodeRadiusFromEffort(
  actualEffortHours: number,
  mttrOrLeadHours: number
): number {
  const effortComponent = Math.sqrt(Math.max(1, actualEffortHours)) * 6.5;
  const flowComponent = Math.log10(Math.max(2, mttrOrLeadHours + 2)) * 5.5;
  return Math.min(54, Math.max(22, Math.round(14 + effortComponent + flowComponent)));
}

            screenY: e.global.y,
          });
        }

        function handlePointerOut(): void {
          if (!isDragging) {
            setHoveredItem(null);
          }
        }

        function handlePointerDown(e: FederatedPointerEvent): void {
          e.stopPropagation();
          isDragging = true;
          pointerMovedDistance = 0;
          nodeContainer.cursor = 'grabbing';
          nodeContainer.alpha = 0.85;
          dragStartPos = world.toLocal(e.global);
        }

        function handleGlobalPointerMove(e: FederatedPointerEvent): void {
          if (!isDragging) {
            return;
          }
          const currentLocal = world.toLocal(e.global);
          const dx = currentLocal.x - dragStartPos.x;
          const dy = currentLocal.y - dragStartPos.y;
          pointerMovedDistance += Math.hypot(dx, dy);
          nodeContainer.position.x += dx;
          nodeContainer.position.y += dy;
          dragStartPos = currentLocal;
        }

        async function finishInteraction(): Promise<void> {
          if (!isDragging) {
            return;
          }
          isDragging = false;
          nodeContainer.cursor = 'grab';
          nodeContainer.alpha = 1;

          if (pointerMovedDistance < 6) {
            onSelectDefectForWorkbench(defect.id);
            return;
          }

          const dropX = Math.max(0, Math.min(CANVAS_WIDTH - 1, nodeContainer.position.x));
          const targetLaneIndex = Math.min(
            TRIAGE_LANES.length - 1,
            Math.floor(dropX / LANE_WIDTH)
          );
          const targetLane = TRIAGE_LANES[targetLaneIndex];

          nodeContainer.position.x = targetLane.xStart + LANE_WIDTH / 2;

          if (targetLane.targetStatus !== defect.status) {
            await defmanApi.resolveDefect(defect.id, {
              status: targetLane.targetStatus,
            });
            onStatusChanged();
          }
        }

        nodeContainer.on('pointerover', handlePointerOver);
        nodeContainer.on('pointerout', handlePointerOut);
        nodeContainer.on('pointerdown', handlePointerDown);
        nodeContainer.on('globalpointermove', handleGlobalPointerMove);
        nodeContainer.on('pointerup', finishInteraction);
        nodeContainer.on('pointerupoutside', finishInteraction);

        world.addChild(nodeContainer);
      });

      let stagePanning = false;
      let panLast = { x: 0, y: 0 };

      app.stage.eventMode = 'static';
      app.stage.hitArea = app.screen;

      function handleStagePointerDown(e: FederatedPointerEvent): void {
        stagePanning = true;
        panLast = { x: e.global.x, y: e.global.y };
      }

      function handleStagePointerMove(e: FederatedPointerEvent): void {
        if (!stagePanning) {
          return;
        }
        world.position.x += e.global.x - panLast.x;
        world.position.y += e.global.y - panLast.y;
        panLast = { x: e.global.x, y: e.global.y };
      }

      function handleStagePointerUp(): void {
        stagePanning = false;
      }

      function onWheel(e: WheelEvent): void {
        e.preventDefault();
        const factor = e.deltaY < 0 ? 1.1 : 0.9;
        const nextScale = Math.min(2.2, Math.max(0.55, world.scale.x * factor));
        world.scale.set(nextScale);
        setZoomLevel(Number(nextScale.toFixed(2)));
      }

      app.stage.on('pointerdown', handleStagePointerDown);
      app.stage.on('globalpointermove', handleStagePointerMove);
      app.stage.on('pointerup', handleStagePointerUp);
      app.canvas.addEventListener('wheel', onWheel, { passive: false });
    }

    initPixiCanvas();

    return function cleanupPixiCanvas(): void {
      destroyed = true;
      try {
        app.destroy(true, { children: true });
      } catch {
        // Safe cleanup if unmount occurs mid-init
      }
    };
  }, [items, onSelectDefectForWorkbench, onStatusChanged]);

  return (
    <div className="bg-slate-900 border border-slate-700 rounded-xl p-4 text-slate-100 shadow-xl space-y-3 relative">
      <div className="flex flex-wrap items-center justify-between gap-3">
        <div>
          <h2 className="text-lg font-bold text-amber-400">
            Visual Defect Triage &amp; IEEE 1044-2009 / DORA Flow Canvas
          </h2>
          <p className="text-xs text-slate-400">
            Drag nodes across lanes (Open → Analyzing → Fixed → Resolved) to trigger{' '}
            <code className="text-amber-300">PUT /api/defects/&#123;id&#125;/resolve</code>, or click any node to open{' '}
            <code className="text-amber-300">&lt;DefectAnalyzerWorkbench /&gt;</code>.
          </p>
        </div>
        <div className="flex items-center gap-3 text-xs">
          <span className="px-2.5 py-1 rounded bg-slate-800 border border-slate-700 font-mono text-emerald-400">
            {rendererBackend}
          </span>
          <span className="px-2.5 py-1 rounded bg-slate-800 border border-slate-700 font-mono">
            Zoom: {Math.round(zoomLevel * 100)}%
          </span>
        </div>
      </div>

      {/* IEEE Std 1044-2009 Root Cause Color Legend */}
      <div className="flex flex-wrap items-center gap-2 text-[11px] bg-slate-950/70 p-2.5 rounded-lg border border-slate-800">
        <span className="font-semibold text-slate-400 mr-1">
          IEEE 1044-2009 Root Cause:
        </span>
        {Object.values(IeeeFaultType).map(function renderLegendChip(fault) {
          const hex = IEEE_FAULT_HEX_COLORS[fault] ?? 0x64748b;
          return (
            <span
              key={fault}
              className="flex items-center gap-1.5 px-2 py-0.5 rounded bg-slate-900 border border-slate-800"
            >
              <span
                className="w-2.5 h-2.5 rounded-full inline-block"
                style={{
                  backgroundColor: `#${hex.toString(16).padStart(6, '0')}`,
                }}
              />
              <span>{fault}</span>
            </span>
          );
        })}
      </div>

      {/* PixiJS v8 Viewport Host */}
      <div
        ref={hostRef}
        className="w-full overflow-hidden rounded-lg border border-slate-800 bg-slate-950"
      />

      {/* Hover Telemetry Tooltip */}
      {hoveredItem && (
        <div
          className="pointer-events-none absolute z-30 bg-slate-950/95 border border-amber-500/60 rounded-lg p-3 text-xs shadow-2xl max-w-xs space-y-1"
          style={{
            left: Math.min(CANVAS_WIDTH - 280, hoveredItem.screenX + 24),
            top: Math.max(80, hoveredItem.screenY + 40),
          }}
        >
          <div className="font-bold text-amber-400">
            #{hoveredItem.item.id} — {hoveredItem.item.title}
          </div>
          <div className="text-slate-300">
            <strong>Product:</strong> {hoveredItem.item.product} ({hoveredItem.item.detected_environment || 'PROD'})
          </div>
          <div>
            <strong>IEEE 1044-2009 Root Cause:</strong>{' '}
            {hoveredItem.item.root_cause_type || hoveredItem.item.classification}
          </div>
          <div>
            <strong>Symptom:</strong> {hoveredItem.item.symptom_category || '—'}
          </div>
          <div>
            <strong>Severity / Priority:</strong> {hoveredItem.item.severity} /{' '}
            {hoveredItem.item.priority}
            {Boolean(hoveredItem.item.is_regression) ? ' • [REGRESSION]' : ''}
          </div>
          <div>
            <strong>Actual Effort:</strong>{' '}
            {Number(hoveredItem.item.actual_effort_hours ?? hoveredItem.item.fixeffort ?? 0).toFixed(2)}h
          </div>
          <div>
            <strong>Triage Lead / MTTR:</strong>{' '}
            {hoveredItem.item.triage_lead_time_hours !== null && hoveredItem.item.triage_lead_time_hours !== undefined
              ? `${hoveredItem.item.triage_lead_time_hours}h`
              : '—'}{' '}
            /{' '}
            {hoveredItem.item.mttr_hours !== null && hoveredItem.item.mttr_hours !== undefined
              ? `${hoveredItem.item.mttr_hours}h`
              : 'open'}
          </div>
          {(hoveredItem.item.introducing_ref || hoveredItem.item.resolution_ref) && (
            <div className="font-mono text-[10px] text-emerald-300">
              {hoveredItem.item.introducing_ref ? `Intro: ${hoveredItem.item.introducing_ref} ` : ''}
              {hoveredItem.item.resolution_ref ? `Fix: ${hoveredItem.item.resolution_ref}` : ''}
            </div>
          )}
          <div className="text-[10px] text-amber-300 pt-1">
            Click node to open Telemetry Workbench • Drag across lanes to update status
          </div>
        </div>
      )}
    </div>
  );
}
